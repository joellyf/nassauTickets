# Direção visual inicial

Protótipo de interface clínica, com leitura clara e orientação em cada etapa. Identidade proposta para a atividade, não marca oficial de uma instituição.

- Verde profundo `#164e42`: ações primárias e painel de chamada.
- Fundo `#f5f6f1` e superfícies `#fffef9`: contraste e separação de áreas.
- Verde claro `#d6ed9f`: destaque prioritário; o significado também aparece por texto/sigla.
- Texto `#183d38`, secundário `#526660`; foco visível em `#aa510d`.
- Títulos em Georgia; corpo em Segoe UI; senha em Cascadia Mono/Consolas, com fallbacks locais. Sem downloads de fontes.
- Botões principais com pelo menos 48 px de altura, navegação sem depender de cor, zoom permitido, layout de uma coluna no celular.

Tokens e estilos: frontend/src/theme/app.css. Validar acessibilidade completa com usuários e ferramenta apropriada em etapa posterior; não declarar conformidade integral com WCAG nesta entrega.
